# 方法选择与最小实验

## 参考边界

Lenny Rachitsky 的 [Find your early adopters by doing things that don’t scale](https://www.lennysnewsletter.com/p/consumer-business-find-first-users)（2022-07-26）提供七类消费产品早期思路：熟人、定向陌生人、用户聚集地、影响者、媒体、传播内容、线下触点。借用聚焦少数方式的原则，不照搬历史平台、成功率、伪装身份或当年的具体操作。

以下路由是本 Skill 的工作假设，不是文章结论或增长保证。B2B、开发者产品、交易平台和本地服务要按自身采购、供需和使用路径调整。

## 按产品结构路由

| 产品结构 | 值得先评估 | 不宜默认优先 |
|---|---|---|
| 插件、个人效率工具 | 场景求助、主动试用邀请、短演示、商店承接 | 宽泛群发、假定整个效率人群都需要 |
| 垂直 B2B | 特定岗位问题、少量个性化邀请、协助首次任务 | 面向泛科技受众的大型发布 |
| 开发者工具 | 可复现示例、文档、相关技术讨论、生态资源 | 无关 issue 广告、滥建 PR |
| 创作与设计工具 | 前后对比、模板、小创作者实测 | 没有作品的泛化宣传 |
| 内容与学习产品 | 有用片段、目标社群、互补作者合作 | 只有入口没有价值的引流文 |
| 双边平台或市场 | 确定受限一侧，小范围招募和人工撮合 | 两侧一起泛撒流量 |
| 本地服务 | 本地社区、合作场所、小范围现场演示 | 跨地区曝光 |

## 优先级与实验单位

1. 排除不匹配、违规、超预算或当前不能执行的选项。
2. 优先回答最重要的未知问题，比较反馈速度、准备成本和风险。
3. 说明证据强弱，未试验前称推荐尝试，不称最佳渠道已验证。

一个实验包含：人群、场景、方法、表达、一个验证问题、成本、观察窗口和停止条件。通常重点改变一个因素，但不把少量样本伪装成统计实验。

找到首批体验者与验证规模化获客不是同一任务。试用反馈者、同行点赞者和付费客户不能混算。

## 方法菜单

| 方法 | 最小可执行单元 | 优先观察 | 不适用或停止条件 |
|---|---|---|---|
| 熟人试用 | 邀请一位有需求的人完成核心操作 | 是否完成、卡在哪里 | 只有帮忙点赞，没有对应场景 |
| 回应明确求助 | 读一条问题，先给建议，匹配时介绍产品 | 回应与体验意愿 | 已解决、禁止推广、不匹配 |
| 主动试用征集 | 回应一条明确试用邀请，给简短测试步骤 | 首次理解和使用障碍 | 把评论当验证、要求好评 |
| 定向邀请 | 给一位有可核实需求的人一个具体请求 | 是否愿意交流或体验 | 缺联系许可、拒绝或规则禁止 |
| 协助首次获得价值 | 经同意陪一位用户完成真实任务 | 核心结果和重复使用意愿 | 超权限、服务成本不可持续 |
| 场景演示 | 展示一个真实问题的处理前后与入口 | 对应人群理解和尝试 | 功能未验证、虚构效果 |
| 垂直社区分享 | 在允许栏目分享一个具体工作流 | 相关问题与体验反馈 | 只贴链接、管理员拒绝 |
| 产品发布 | 一个完整发布页和体验路径 | 合格访问、激活、问题 | 不可体验、素材成本过高 |
| 目录收录 | 一个匹配且规则明确的入口 | 收录、可归因访问 | 隐藏收费、低质目录、重复提交 |
| 商店发现与转化 | 改一个定位要素或使用截图，先给改稿 | 列表访问到体验的变化 | 无权限、需要另行发布版本 |
| 长尾问题内容 | 回答一个真实问题，给实践步骤 | 索引、合格访问、核心操作 | 需要即时反馈却只安排长期内容 |
| 小创作者合作 | 一位受众吻合作者的可复现试用方案 | 测试意愿、受众匹配 | 超预算、要求正面评价 |
| 互补产品合作 | 一项双方用户受益的联合工作流 | 对方兴趣与使用 | 只有交换流量，没有互补价值 |
| 模板或小资源 | 一个独立有用的示例、模板或清单 | 资源使用、自然产品体验 | 无用资源夹带广告 |
| 用户转介绍 | 向已获价值且愿意交流的用户提一次邀请 | 合格推荐和体验 | 无满意用户、奖励未批准 |
| 媒体与通讯投稿 | 给一位匹配编辑新信息和体验入口 | 编辑回复、合格曝光 | 无新闻点、群发新闻稿 |
| 线下触点 | 一个获许可场所的任务演示 | 现场体验、后续使用 | 许可、地理和费用不明 |

每次按产品选少数方法，不为展示知识输出整张菜单。

## 边界示例：标签页工具

- 保存跨项目研究链接：可能适合保存与分类工具，先核实能力。
- “收藏后就忘了，开着才提醒”：区分找回与提醒，没有提醒能力就承认，不把分类说成提醒。
- 数千个活跃标签页即时切换：无对应能力和性能证据时，不推销保存链接工具。
- PDF、截图、文档交给 AI 问答：不能用只处理链接元数据的产品冒充知识库。
- 现有工具已更新并解决问题：不包装成未解决求助。

这些是需求判定示例，不包含任何特定产品当前的价格、品牌或功能事实。
