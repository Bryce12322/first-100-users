## 本地安装环境与可复现方式

- 系统：macOS。
- Node.js：22.17.1；现有 Skills CLI：1.5.1。
- Python：3.13.4；PyYAML：6.0.3，仅用于维护者的格式检查，不是技能使用依赖。
- 使用现有缓存 CLI，不下载或更新客户端；安装目标与 CLI 状态文件均隔离在临时目录，关闭该次 CLI 遥测，不覆盖用户现有技能。

安装检查对应的公开命令形式如下，路径按实际下载目录填写：

```bash
npx skills add "/path/to/first-100-users-release" --list
npx skills add "/path/to/first-100-users-release" --skill first-100-users -a codex --copy -y
npx skills list -a codex --json
```

本次直接调用缓存 CLI 的入口完成上述检查，因此没有验证 `npx` 首次下载。远程测试使用 `add Bryce12322/first-100-users --skill first-100-users -a codex --copy -y`；环境的普通联网路径无法解析 GitHub 后，在获准联网的隔离临时项目中完成，未覆盖现有技能。

当前上游最新 CLI 文档要求 Node.js 22.20 或更高版本；README 按上游要求编写，不把旧版本地测试等同于最新版兼容认证。[上游说明](https://github.com/vercel-labs/skills)
